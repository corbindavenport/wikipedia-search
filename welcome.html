How to use Wikipedia Search

You can type "wiki" in the browser search bar, then the Space or Tab key, to start a search with live suggestions as you type. Also, selecting a word or phrase in a web page and opening the context menu will show a Wikipedia search option.

From the extension settings, you can change the default search language to any language Wikipedia supports, and the optional multi-language search feature can override it with a different choice. Search results can be opened in the desktop Wikipedia site, the mobile site, or Wikiwand.
