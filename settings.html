Wikipedia Search settings

Here you can change all the options for Wikipedia Search. Your changes are automatically saved.

The language list is updated every time you open this settings page, using the Wikipedia Query API.
Search in a different language by typing a Wikipedia language prefix before your search. For example, "fr google" searches "Google" in French Wikipedia. Turn this off if you accidentally search in different languages with queries like "La Niña".
